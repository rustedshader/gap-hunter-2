## In-Scope Subcategory Assessments

### ID.AM-7 — Identify: Asset Management
**Status**: Partially Addressed
**Evidence from Policy**: Snippet 1: 2. Data Classification All company data is classified into two categories: 3. Public: Information freely available to anyone (e.g., marketing materials). 4. Confidential: Customer data, employee records, and financial data.
**Gap**: The policy defines data classification (Public and Confidential), which addresses the need to classify data. However, it does not explicitly detail the maintenance of inventories of data and corresponding metadata (owner, location, retention schedule, access controls) as required by the Implementation Guidance and Key Questions for ID.AM-7. The evidence does not confirm if a data discovery exercise has been conducted, if locations are documented, or if retention schedules are enforced.
**Recommendation**: The policy needs to be expanded to include procedures for conducting data discovery exercises, documenting metadata (owner, location, retention schedule, access controls), and integrating with DLP/privacy management tools to fully meet the requirements of ID.AM-7.
