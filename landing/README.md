# Gap Hunter Landing

Standalone Next.js App Router landing page for Gap Hunter Studio.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS v4
- shadcn-style UI primitives copied into the repo for ownership and customization

## Run locally

```bash
cd landing
npm install
npm run dev
```

Open `http://localhost:3000`.

## Validate

```bash
cd landing
npm run build
npm run lint
```

## Design direction

- Editorial command-center aesthetic
- Fraunces display type with Manrope body copy
- Warm parchment background with deep green surfaces and ember CTAs
- Product-first visuals instead of generic stock-marketing patterns
